## Projeto atual

### Diretoria Gestão

O Diretoria Gestão nasceu de uma necessidade real de uma conveniência: centralizar estoque, vendas, caixa, fiados e cadastros que antes dependiam de controles manuais.

A aplicação funciona em Desktop e Android. O computador mantém a API e o banco SQLite; o celular acessa os mesmos dados pela rede local, sem depender de internet durante a operação.

```text
Desktop (Electron + React)
        |
        | API local / LAN
        v
Node.js + Express + SQLite
        ^
        |
Android (Capacitor + React)
```

Entre os fluxos já implementados estão PDV, produtos e estoque, clientes, fornecedores, fiados, caixa, relatórios, leitura de código de barras e pareamento do celular com o computador.

O código principal permanece privado. A documentação e as partes adequadas para apresentação ficam no repositório público [diretoria-gestao-showcase](https://github.com/LeoBilhalva/diretoria-gestao-showcase).
