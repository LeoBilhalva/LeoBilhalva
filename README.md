## 🚀 Projeto em destaque

### Diretoria Gestão

O **Diretoria Gestão** é um sistema desenvolvido especificamente para a empresa **Diretoria**, uma conveniência que precisava centralizar controles antes realizados de forma manual.

A solução está sendo construída com aplicações **Desktop + Android**, comunicação pela **rede local mesmo sem internet** e banco de dados centralizado no computador da empresa.

**Funcionalidades em desenvolvimento**
- PDV e registro de vendas
- produtos, estoque e movimentações
- clientes e fornecedores
- controle de fiados e recebimentos
- caixa e detalhamento de movimentações
- relatórios operacionais
- leitura de códigos de barras no Android
- suporte a leitor de código de barras no Desktop
- pareamento entre celular e computador pela rede local
- exportação e backup de dados
