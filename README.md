# Olá, eu sou Leonardo Bilhalva 👋

Sou estudante de **Banco de Dados na PUCRS** e desenvolvedor focado em transformar problemas reais em sistemas úteis, com atenção a **dados, automação, integração e experiência de uso**.

Atualmente estou desenvolvendo o **Diretoria Gestão**, um sistema de gestão para pequenos negócios com aplicações **Desktop + Android**, operação pela **rede local mesmo sem internet**, controle de estoque, vendas, clientes, fornecedores, fiados, caixa, relatórios e leitura de códigos de barras.

> O núcleo comercial do Diretoria Gestão é mantido em repositório privado. O perfil público apresenta documentação, decisões técnicas, demonstrações e projetos que posso compartilhar sem expor código proprietário ou dados de clientes.

## 🚀 Projeto em destaque

### Diretoria Gestão
Sistema em desenvolvimento para gestão operacional de uma conveniência.

**Principais características**
- Desktop e Mobile conectados pela mesma rede local
- Funcionamento sem dependência de internet
- PDV e lançamento de vendas
- Produtos, estoque e movimentações
- Clientes, fornecedores e fiados
- Caixa e relatórios
- Leitura de código de barras por câmera no Android
- Suporte a leitor de código de barras no Desktop
- Banco de dados local centralizado
- Exportação e evolução contínua baseada em uso real

## 🧠 Como gosto de desenvolver

Procuro entender o problema antes de escolher a tecnologia. Nos projetos, gosto de trabalhar com:
